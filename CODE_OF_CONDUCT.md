# Community Conduct

PulseGuard welcomes respectful technical collaboration.

Contributors are expected to:

- discuss ideas and defects constructively
- focus criticism on code and behavior, not people
- respect privacy and confidentiality
- avoid harassment, discrimination, threats, or personal attacks
- disclose conflicts of interest
- report security concerns privately

Repository maintainers may edit or remove content and restrict participation when conduct puts contributors, users, or the project at risk.
