Architecture

Evidence path

  1. Services expose metrics and health signals.
  2. Prometheus stores the observed state.
  3. Detection logic confirms an operational symptom.
  4. The incident record becomes the investigation boundary.
  5. The agent receives telemetry summaries, topology, and bounded context.
  6. The recommendation includes evidence and uncertainty.

Action path

  1. Policy evaluates the proposed action.
  2. Denied or human-only actions stop.
  3. Approval-required actions wait for authorization.
  4. The automation service executes an allowlisted action.
  5. Telemetry verifies recovery.
  6. The incident resolves or is assigned to support.

Public and internal naming

PulseGuard is the public product name. Existing internal names beginning with opsai- remain in Docker services, images, metrics, and APIs to avoid a risky compatibility migration.
