Trust boundaries

Security and AI boundaries

PulseGuard is designed to demonstrate controlled agentic behavior. Model output is advisory until policy, authorization, execution, and verification agree.

Bounded evidence

The agent receives incident facts, telemetry summaries, topology, and transparent knowledge rather than unrestricted logs and host access.

Bounded authority

Only allowlisted actions can move to automation. Approval-required and human-only decisions stop at the policy boundary.

Observed recovery

An action is not considered successful until service telemetry confirms recovery.

Allowed investigation context

  • incident metadata
  • latency, error, availability, and saturation summaries
  • service topology and dependencies
  • bounded automation state
  • curated local operational knowledge
  • aggregate public traffic indicators

Excluded context

  • credentials and environment dumps
  • raw Wikimedia event payloads
  • scenario-controller ground truth
  • unrelated logs and incidents
  • customer, personal, or corporate data
  • unrestricted infrastructure control
