# Payment node isolated latency

1. Confirm the node is an outlier against peer-node p95 latency.
2. Check retry rate, checkout p95, failure percentage and active-node capacity.
3. Collect diagnostics.
4. If two healthy nodes remain, request approval to drain the degraded node.
5. Verify customer latency and throughput after isolation.
6. Restart or rollback only with explicit approval.
